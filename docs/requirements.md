# 需求口径

本文档固化当前仓库的 MVP 口径，作为后续协作、接口对齐和任务拆分的基础。当前口径以代码实现为准，主要参考后端 Controller、权限服务、数据库迁移脚本、前端路由和 README。

## MVP 目标

新员工“一人一画像”培养管理平台用于支撑新员工培养过程中的人员管理、学习记录、闯关任务、考试评价、综合评分和权限分层管理。当前 MVP 的目标是形成可本地运行、可演示核心业务闭环、可继续多人协作开发的版本。

当前 MVP 需要回答三个问题：

- 培训管理方能维护人员、课程、任务、考试和评价规则。
- 新员工能查看自己的培养过程，完成签到、任务提交和考试。
- 导师、站点负责人、培训管理员、管理员和超级管理员能按角色权限处理各自范围内的数据。

## 目标用户

| 角色 | 当前定位 |
| --- | --- |
| `EMPLOYEE` | 新员工，查看本人进度，完成课程签到、任务提交、考试作答，查看已发布评价结果。 |
| `MENTOR` | 导师，查看所带员工，提交导师月度评价。 |
| `STATION_MANAGER` | 站点负责人，查看绑定服务站员工，提交站点评价。 |
| `TRAINING_ADMIN` | 培训管理员，管理课程、签到、任务、考试、评价，提交培训方评价。 |
| `ADMIN` | 管理员，维护人员信息、基础数据、员工账号、审计查询和大部分业务配置。 |
| `SUPER_ADMIN` | 超级管理员，拥有管理员能力，并可管理非员工角色账号。 |

## 核心业务闭环

1. 超级管理员或管理员准备基础数据，包括培养批次、所属板块、服务站、导师和人员信息。
2. 管理端创建员工账号。员工账号默认需要首次改密，导入员工时账号默认停用。
3. 培训管理员创建课程和场次，将员工安排到课程场次。
4. 员工使用签到码在签到时间窗口内完成课程签到；培训管理员可补录或导入签到记录。
5. 培训管理员创建培养任务，并按批次、所属板块或服务站分配。
6. 员工提交任务成果和附件；有审核权限的角色进行通过、退回和评分。
7. 考试管理员维护题库、试卷和考试计划，将考试分配给员工并发布。
8. 员工在开放时间内开始考试、自动保存答案、提交答卷；客观题立即自动评分，管理员可即时核对，员工在整场考试结束后收到自动下发结果。
9. 评价管理员维护评分方案，系统汇总考试、任务、导师评价、站点评价、培训评价和加扣分。
10. 评价管理员生成并发布月度或季度汇总；管理员可在需要时重开已发布月度汇总。
11. 员工在外出、出差或客户现场支持时自主报备位置变化和原因；导师及管理角色按人员范围查看流动信息。
12. 用户按角色和数据范围查看进度概览、人员信息、评价结果和审计记录。

## 当前已支持范围

### 登录与安全

- 支持用户名密码登录，登录成功后返回 JWT 和当前用户信息。
- 支持 `/api/v1/auth/me` 获取当前登录用户。
- 支持首次登录强制修改密码。
- 账号停用、角色调整和密码重置会递增 `security_version`，旧令牌失效。
- 前端路由会拦截未登录用户，并在 `mustChangePassword=true` 时强制进入“账号设置”页。

### 人员管理

- “人员管理”作为一级业务模块，依次下设“人员台账”“人员流动”和“调站审批”；调站审批继续按 `master:manage` 权限控制，仅对有审批权限的角色显示。
- 使用统一人员台账页面完成分页查询、完整档案、新增、编辑和批量设置技术/技能导师，不再保留重复的独立维护页面。
- 人员台账工作台提供权限范围内的人员、在职、站点分配和双导师配置概览，并通过状态页签和组合筛选快速定位待完善档案。
- 人员列表保持每人一行的字段展示，直接呈现教育背景和联系方式，并沿用原有查看、编辑、站点历史操作逻辑；培训管理员可更新现有档案，但新增、导入和批量绑定仍仅开放给人员管理员。外层布局、筛选层级和移动端适配与人员流动等管理页面保持一致。
- 支持姓名、工号、批次、所属板块、服务站点、技术/技能导师、身份证号码、教育背景、籍贯、政治面貌、公司住址、兴趣爱好、特长、私人邮箱、联系方式和状态维护。
- 支持员工 Excel 模板下载和整批导入；任一行校验失败时整批不写入。
- 支持人员目录多条件查询和 Excel 导出。
- 支持员工申请变更服务站，由管理员审批通过后更新人员信息并保留历史；管理员直接编辑站点同样写入已生效历史。
- 调站审批工作台支持待办/当日处理统计、平均等待时长、人员/站点/日期筛选、人员归属信息、申请详情和已生效历史；拒绝必须填写原因，过期申请不得覆盖已变化的人员归属。
- 人员详情、课程、签到、任务、评价、考试等员工关联查询受数据范围约束：本人、导师所带员工、站点范围或全量。

### 基础数据

- 支持培养批次、所属板块和服务站点查询。
- 支持管理员创建培养批次、所属板块和服务站点。
- 支持查询启用状态的导师账号。

### 位置报备与人员流动

- 员工可提交本人新位置、实际变动时间、自由文本原因和可选预计返回时间，并查看本人当前位置与历史轨迹。
- 系统根据归属服务站或上一条报备自动确定起点；禁止倒序补录，保证轨迹连续可读。
- 导师查看所带员工，站点负责人查看所辖站点员工，培训管理员、管理员和超级管理员查看全量员工。
- 管理侧提供当前位置、历史记录、关键字/地点/日期筛选和今日、近 7 日统计，不设置审批步骤。
- 位置报备只记录临时实际地点，不修改人员归属服务站；正式调站仍使用服务站变更申请。

### 课程与签到

- 管理端“课程管理”作为一级模块，下设课程库、场次安排、课件管理和签到管理；员工端下设我的课程、课件学习和签到记录。
- 课程库支持统计、搜索、创建、编辑、启停和安全删除，并集中维护可跨场次复用的课程课件。
- 课件接收 DOC/DOCX、PDF、PPT/PPTX、OFD、PNG、JPG/JPEG，并校验扩展名对应的真实文件结构。服务端使用 LibreOffice、OFDRW、PDFBox 或 ImageIO 统一逐页渲染，只返回带当前员工姓名、工号的水印图片，不向浏览器返回原文件；员工仅能访问已安排课程的课件。
- 员工课件学习页只显示本人可学习课件及“已学习/未学习”，不显示查看次数和学习时长。管理端课件列表显示应学习、已学习、未学习人数，员工明细显示学习状态、次数和累计时长。
- 场次安排支持时间、地点、学时、签到窗口、签到码和参加人员的完整维护。
- 支持员工在签到窗口内使用 6 位签到码签到，并阻止重复签到。
- 支持管理员补录签到和 Excel 批量导入，补录会保留来源与说明。
- 支持按员工数据范围、课程、场次、签到来源和日期查询签到记录。
- 已形成签到历史的场次或人员安排不可删除，课程与场次停用/删除操作保留业务历史。

### 任务下发与任务跟踪

- 支持从已启用培养计划批量下发任务，也可创建临时任务。
- 支持按批次、所属板块和服务站组合筛选在职员工，多个条件按交集生效，并在正式下发前预览覆盖人数、任务数量和复用情况。
- 支持在任务编辑中上传、删除、预览和下载任务附件；任务列表直接显示附件文件名，点击即可预览。
- 支持员工提交文字说明和最多 5 个附件。
- 支持任务提交历史查看。
- 支持审核通过、退回和评分。
- 支持任务资料与员工成果附件分别管理，文件访问权限均按任务所属员工的数据范围控制。

### 培养计划

- 培养计划作为一级业务模块，下设“计划管理”“任务编排”“任务下发”和“任务跟踪”四个独立入口。
- 计划管理支持计划库统计、搜索、状态筛选、草稿创建、编辑、复制、启停和安全删除。
- 任务编排支持按计划集中维护任务名称、说明、成果要求、任务附件与执行顺序，并展示任务是否已投入使用。
- 新计划默认为草稿，至少编排一项任务后才允许启用；已有下发历史的计划和任务不可删除，只能停用或继续保留。
- 人员范围、截止时间和实际下发在“任务下发”中配置，避免把稳定的培养模板与单次执行参数混在一起。
- 计划任务下发时生成附件快照；后续模板附件的增删改不会影响已经下发给员工的任务资料。

### 综合评价

- 综合评价作为一级业务模块，管理侧下设“评价工作台”“评分任务”“月度评分”“评价模板”“结果中心”；导师、站点负责人和培训管理员增加“我的评分任务”，员工只显示“我的评价”。
- 评价工作台按月份展示方案覆盖、汇总发布进度、缺失项，以及人工评分、任务审核和遗留主观题阅卷待办，并可跳转到对应专业模块处理；客观题成绩不再产生人工发布待办。
- 评价模板独立于批次和月份，支持创建、编辑、复制、删除；每个模板可配置考试、任务、导师、站点、培训五类评分项的启停、本项满分、综合权重、季度权重及加扣分上限。任务与考试还可对具体项目设置内部权重，未单独设置的当月项目平分剩余权重。
- 模板应用到指定批次和生效月份后生成方案草稿，发布后才参与计算；后续编辑模板不会回写已应用方案，历史结果保存当时的分项快照。
- 考试与任务属于自动来源：系统按模板内部权重汇总当月各考试和任务，再换算到本项满分并按综合权重计入百分制总分；存在正权重但尚无成绩的来源时，该项保持待完成。
- 每月按“员工 + 人工评分项 + 评分作用域”生成评分任务；管理员可为导师、站点、培训任务分配一名或多名同角色评分人，并批量调整截止时间与说明。系统保留已移除评分人的历史评分，但只按当前有效评分人判断完成状态和计算结果。
- 每位当前评分人独立提交个人分数；未全部提交时只显示过程平均分，全部提交后才形成该任务正式算术平均分。导师任务默认带入技术导师与技能导师，站点任务默认带入对应站点负责人，培训任务由管理员显式分配。
- 员工当月发生站点变更时，站点评价默认按各站实际在站天数加权，也可在模板中仅采用在站最久站点；管理员还可仅针对某员工某月手动设置各站权重，各站负责人只评价本人管理的站点。
- 月度评分以员工待评队列作为评分工作区；评分人也可从“我的评分任务”按本人待办进入。页面展示“待我评价、进行中、已齐全、已发布、未配置方案”状态，并支持自动来源核对、职责内手工评分、管理员人工核定和加扣分；已发布结果锁定，管理员重开时保留旧版本。
- 结果中心支持月度、季度汇总的生成、核对、发布与历史追溯；缺失评分项时必须由管理员填写豁免原因并核定最终分数。

### 考试中心

- 支持创建多个独立题库，按业务主题维护题库名称、说明和启停状态；历史题目升级时自动归入默认题库。
- 题库可保留单选、多选、判断、简答题历史数据；新建自动评分试卷只允许选择单选、多选和判断题，已被试卷或答卷使用的题目不得物理删除。
- 支持选择目标题库后下载模板和 Excel 批量导入。
- 支持按指定题库手动组卷、随机组卷和按员工专业标签动态生成“一人一卷”，试卷总分必须为 100 分；试卷可查看结构详情，已用于考试计划后受历史保护。
- 支持考试计划创建、发布、草稿安全删除、补充分配和次数限制。
- 支持员工开考、保存答案、防作弊事件记录和提交答卷。
- 员工交卷时系统立即完成客观题评分，管理员可即时查看成绩；交卷响应不返回分数，员工在整场考试结束前不能查询成绩。
- 定时任务每分钟处理超时答卷，并在考试计划结束后自动下发该场已评分成绩；人工单份或批量发布入口停用。历史含简答题答卷仍保留人工阅卷兼容能力，完成评分后同样等待考试结束自动下发。
- 支持员工查看考试结束后已自动下发的结果。
- 支持按考试计划、成绩月份或专业筛选导出已发布成绩。

### 账号权限与审计

- 支持员工账号列表、启停和重置密码。
- 超级管理员支持创建和管理导师、站点负责人、培训管理员、管理员账号。
- 支持站点负责人绑定服务站范围。
- 支持审计日志查询，覆盖登录、创建、更新、导入、发布、审核等关键操作。

### 进度概览

- 进度概览按角色分为员工个人学习主页与管理培养运营工作台，两类页面保持与人员、课程、任务和综合评价模块一致的布局与视觉规范。
- 员工主页展示待处理/已完成任务、近期课程、待参加考试、任务/课程/考试完成进度、未来 30 天学习日程、已发布季度评分、导师评价和最近完成任务；未发布的考试成绩和评价结果不得提前展示。
- 管理工作台按当前数据范围展示员工数、职责待办、任务完成率、本月评价覆盖率，以及任务、课程、考试和综合评价四条业务链路的执行指标。
- 管理工作台仅聚合当前角色有权限处理的任务审核、遗留主观题批阅、人工评价、月度评价推进和签到补录入口；客观题成绩由系统到期自动下发，不形成待办。导师、站点负责人和管理角色的数据范围必须分别保持 `MENTORED`、`STATION` 和 `ALL`。
- 管理工作台展示未来 30 天课程/考试安排，并按逾期任务、退回任务、缺考和本月评价未发布识别需要关注的员工；所有待办和异常项应可跳转到对应专业模块处理。

## 当前不支持范围

当前 MVP 明确不覆盖以下能力：

- 生产级 SSO、LDAP、企业微信或钉钉统一认证。
- 短信、邮件、站内信或待办通知。
- 外部 HR、OA、LMS、考试系统或数据仓库同步。
- 多级审批流、电子签章和复杂流程编排。
- 原生移动 App、小程序或离线端。
- 真实实时音视频监考、摄像头抓拍、人脸识别和 AI 作弊判定。
- 生产部署拓扑、高可用、备份恢复、容量规划和 SLA 规范。
- 细粒度字段级脱敏、租户隔离、组织树和动态权限配置。
- 完整 OpenAPI/Swagger 自动生成合同。

## 验收口径

- 新协作者能从本文档理解当前 MVP 做什么、不做什么。
- 涉及角色、权限、接口和任务拆分时，以 `docs/api-contract.md`、`docs/permissions-matrix.md` 和 `docs/task-board.md` 为协作入口。
- 如果后续代码改动改变业务边界、接口形态或权限行为，必须同步更新对应文档。
