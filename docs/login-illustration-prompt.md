## 图片接入

- 推荐透明 PNG 或 WebP；建议压缩至 500 KB 左右，并保留原始高清图。
- 放置于 `frontend/src/assets/`，使用 Vite 的静态资源导入，兼容已有 CDN 构建配置。
- 当前登录页使用 `.brand-art` 铺满左侧背景。若以后改用透明插画，应同时调整为独立插画容器，避免直接沿用铺满裁切方式。
- 平台全称、Logo 和登录表单由网页呈现，不要烘焙进图片。
