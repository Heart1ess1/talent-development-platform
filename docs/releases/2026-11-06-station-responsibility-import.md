# 2026-11-06 站长与区域经理批量导入

## 功能

统一五列模板按服务站导入站长、区域经理。工号精确匹配账号并核对姓名、角色和启用状态；不存在时在确认事务内创建账号，初始密码为工号后六位，不足六位使用完整工号，首次登录强制改密。空白保留原配置，多行人员合并后替换同站同级负责人；新账号也可接收待审批或未销假的请假责任。

新增预览、逐行错误及处理建议、错误Excel下载、前后配置、账号创建与复用明细、交接选择、导入结果查询。批次行锁、30分钟预览基线、同事务提交和七天批次清理保证并发、重试和失败回滚。负责人展示姓名与账号，服务站搜索支持账号。

数据库新增V51 `station_responsibility_import`，不修改旧迁移、账号和范围表。接口与原手动调整兼容，权限为`user:ops-role:manage`，查询、下载和执行同时校验批次创建人。
