# 请假及负责人维护验收记录

## 隔离验证环境

MySQL 8.4 独立容器、独立数据库，Flyway V1–V48。模拟账号及站点仅用于本机测试。浏览器连接本地 Spring Boot 与 Vue 页面，未向生产写入模拟人员或审批范围。

后端执行 `mvn -q test`，设置 `LEAVE_TEST_DB_URL` 指向隔离数据库：224 项中 218 项通过，6 项其他模块的按需集成测试跳过，失败和错误均为 0。其中 4 项计假测试及 14 项请假／职责维护真实数据库测试通过。

前端执行 `pnpm test`：25 个文件、75 项通过；`pnpm build` 包含 Vue 类型检查及生产构建。

## 核心证据

| 范围 | 已验证行为 |
|---|---|
| 时间规则 | 上午、下午、正午、午夜、周末跨月、无效区间、对应审批层级 |
| 权限 | 对应层级及站点候选、非指定人员审批阻止、跨站读取隔离、未知角色权限为空、新角色不能成为任务评分人 |
| 正常闭环 | 草稿保存恢复、须知勾选后提交、批准计划、实际位置不被计划改变、销假实际轨迹与待办关闭 |
| 版本 | 原批准版本及逾期提醒在变更待审批时继续有效，驳回不替换原计划，新批准切换版本，旧版本销假被阻止 |
| 幂等与事务 | 扫描和销假并发不重新打开待办；两个并发重复提交只有一单；重复销假只有一条实际轨迹；审计失败回滚单据、责任范围及转交操作 |
| 交接 | 未完成责任阻止直接停用；统一保存先授予新范围再转交、移出旧范围；保留原审批操作；缺接任人和过期预览被阻止 |
| 账号批量 | 站长改为区域经理且沿用同一组站点时，范围从站长表迁入区域经理表 |
| 异常分类 | 按时返回但晚填报与实际晚归分开记录；销假自动结束待审批变更 |

## 实际浏览器操作

使用 Playwright、Chrome 和真实本地接口完成：

- 员工半天申请 → 站长批准 → 立即逾期待办 → 员工销假；详情显示“按时返回，销假填报较晚”。
- 一天申请 → 区域经理批准；两天申请 → 培训负责人批准，三个层级分别登录验证。
- 站长变更预览显示 1 项待审批责任，保存后接任站长接收；并行测试变动触发过期预览保护，重新预览后保存。
- 区域经理双栏增加服务站 B，刷新后负责范围仍为 A、B。
- 390×844 移动界面检查，修正双栏移入移出按钮方向及弹窗内容滚动，底部保存入口保持可见。

## 发布边界

生产部署、迁移、登录页面和接口检查单独记录在发布记录中。模拟完整闭环不等于真实员工上线试办；真实审批账号及范围待管理员配置。不在生产运行上述数据库写入测试。
