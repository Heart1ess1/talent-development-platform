# 月度答辩改造验收记录（2026-11-05）

## 变更

取消季度业务计分与展示，保留数据库历史。答辩改为按月手动创建任务，由管理员录入或导入最终成绩；月度方案支持六项启停、满分和权重。历史已发布方案不重算；管理员应选择生效月份发布新方案，下一无答辩月份须显式关闭答辩并重新配置权重。

任务草稿支持人员筛选和跨页选择；员工同月占用由数据库唯一约束保护。启用锁定名单、月份与满分；取消释放占用；已结束任务可修订成绩。导入绑定任务、保留工号前导零，区分空值与零分，支持逐行纠正、幂等和整批发布。成绩修订仅关联月度结果，审核前保留原正式版本。

## 批次筛选与导入导出补充验收

新建/编辑任务的人员筛选栏首位增加培养批次，与任务批次双向同步。切换批次会清空原批次已选人员，同批次内筛选和翻页保留选择；筛选栏自适应排列。任务列表增加“成绩管理”按钮，可直接进入该任务的模板下载、Excel导入和成绩导出。

本地浏览器验证：从人员筛选栏切换到验收批次，选择人员后从上方切换批次，已选归零；切回验收批次跨第1/3页选择两人，保存并启用任务。下载导入模板并填入两行，其中一行空成绩被拦截，逐行修改为0后重新校验、整批发布；另一行88.75分发布成功。通过页面导出Excel并解析核对，文件仅含当前任务两名人员，保留工号前导零、0分、88.75分、月份、满分和正式发布状态。

## 回滚与切换

使用 deploy/aliyun 既有发布脚本：先数据库备份并校验，再上传 CDN 候选包，最后激活并检查。脚本保留旧 JAR 和环境配置；数据库升级使用新增V49/V50，严禁修改已执行的迁移。若需要恢复迁移前数据库，必须使用本次备份并评估部署后新增数据，不能仅通过替换JAR撤销数据库变更。
