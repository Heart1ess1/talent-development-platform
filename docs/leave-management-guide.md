# 请假管理操作与配置说明

## 员工办理

在“我的请假”新建申请。姓名、工号、服务站由系统带出；填写场景、性质、起止时间、去向地点、预计回段地点和原因。结束时间同时作为预计返回时间。因公选项不代表费用可报销。

系统按北京时间的上午、下午分别计 0.5 天，包含周末节假日；结束时间恰为 12:00 不计下午，恰为 00:00 不计次日。0.5 天选择站长，1 天选择区域经理，超过 1 天选择培训负责人，仅由所选层级的一人审批。系统只提供启用且范围有效的账号；缺少人员时联系管理员配置。单次区间最长一年。

提交前阅读请假须知并勾选确认。关闭须知不会正式提交，可以保存草稿后继续填写。开始时间已过的紧急情况可补提，必须填写补提说明；提交及审批时间保留真实时间。

待审批单可以撤回；被驳回或撤回后可以复制重新申请。批准且尚未开始的单据可取消；已经开始的请假通过销假结束。批准后的时间、地点和原因只能申请变更，需重新阅读须知、选择审批人。变更批准前，原计划和原返回期限继续有效。

回段后点击“销假”，填写实际返回时间和地点；时间不得早于请假开始，也不得晚于当前时间。实际晚归或地点变化须填写说明。提交即完成，无需再次审批；同时自动结束尚未审批的变更。系统区分实际晚归与按时返回但较晚填报销假。

## 审批和轨迹

“请假审批”提供待我审批、我已审批、逾期未销假和管理范围记录，可筛选员工、站点、日期、场景及状态。仅指定审批人能够同意或驳回，驳回原因必填。管理员转交权限不等于代审批权限。

批准的记录会显示在人员流动及人员画像时间线中，属于计划行程；当前位置继续由实际位置记录确定。销假生成关联的实际返回轨迹，补销历史记录不会覆盖时间更晚的位置。请假详情保留申请版本、计假依据、须知确认、审批操作和实际返回轨迹。

首页显示审批、待返回／销假和逾期事项。每分钟补扫已超过预计返回时间且未销假的批准单，员工和当前生效版本的审批人收到系统内待办；不发送短信、微信。销假后关闭待办，原异常及转交、变更操作仍可追溯。

## 管理员首次配置

1. 在“账号管理”创建或维护站长、区域经理、培训负责人账号。培训负责人负责全部员工；区域经理、站长按服务站配置。
2. 在“人员管理 → 站长与区域经理管理”检查服务站的负责人配置。也可从账号管理页直接进入。
3. “服务站维护”按站点调整站长、区域经理；“站长管理”“区域经理管理”按人员查看全部负责站点，使用双栏选择器增加、移出站点。
4. 填写调整原因，点击“预览调整”。移出的人员仍有待审批或未销假的责任时，选择同级接任人；按人员调整时也可指定接任人接管移出的站点。
5. “确认保存”在同一事务中完成站点范围、请假责任和未完成待办交接。没有合格接任人时不能遗留未完成责任；预览后数据变化则重新预览。
6. 完成交接后再停用账号或调整角色。保留原审批人操作记录及调整原因。

新角色不获得课程、考试、评分、评价编辑或账号管理权限。管理员负责配置；区域经理和培训负责人可查看其范围内人员、画像、轨迹及请假。

## 本次启用边界

按需求使用隔离环境中的模拟员工、站长、区域经理、培训负责人测试，不自动创建生产审批账号或替真实人员分配职责。正式启用前，由管理员核对员工站点和真实审批人员范围。请假不联动工资、考勤扣减及费用报销计算。
